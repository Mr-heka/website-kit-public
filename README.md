# Website Kit

Made by Selr AI. Public guided edition, version 2.

Build a first business website, a service landing page, or improve an existing
page with your AI coding assistant. The kit helps you turn real business facts
into clear copy, a coherent design and a checked preview.

## Start here

1. Open the project you want to work on in Claude Code or Codex. For a new site,
   choose an empty project folder. You need a coding workspace to run a preview.
2. Open **SKILL.md**, copy its contents into your chat and describe your business.
   You can use it directly; installing a skill is optional.
3. Add your existing site, logo, photos or reference sites if you have them.
   The assistant gathers missing details and works through the build.

**The immediate result:** website source, a preview when your tools support one,
a brief you can edit, and a checklist showing what was checked and what remains.
It will ask before any publication or paid action that you have not authorised.
Hosting, domains, AI usage and optional services are separate.

If you only have a text chat, you can still develop the brief and page copy.
A running website needs a workspace that can save files and run or open the page.

## What's inside

- [SKILL.md](SKILL.md): the complete copy-to-chat workflow. No extra kit files required.
- [Business brief](templates/website-brief.md): an optional worksheet for a better starting point.
- [Launch checklist](templates/launch-checklist.md): separates preview checks from actual delivery.
- [Worked example](examples/moss-and-grain/index.html): a fictional furniture-repair site.
  Open its HTML file in a browser. Its brief and checks explain the decisions and
  which checks were possible. It has no contact form, tracking or real customers.

## Try it

> Use the Website Kit to improve my services page. Keep the current framework and
> routes. My main action is an email enquiry. Read my existing copy and ask for
> missing business facts before using them.

Or:

> Use the Website Kit to build a simple one-page site from this brief. I have no
> brand or photos yet. Make a considered visual direction and a local preview.
> Do not publish it.

To refine a result, name the problem: “The headline does not explain the service”,
“The phone layout feels cramped”, or “The main button has no destination”. Ask the
assistant to fix that problem and recheck the affected behaviour.

## Scope

This edition covers small business websites and focused refreshes. It is not a
store, membership platform, custom application or complete design library. It
contains no global installer, private account configuration or bundled paid tools.
Existing project rules and permissions still apply. No quality rating or business
result is guaranteed; inspect the actual website before launch.

## If something is unavailable

Ask the assistant to identify the exact missing capability and complete what it
can. It should provide files and instructions when it cannot run a preview, and
mark browser or delivery checks unverified. For a failing build, collect the error,
repair the specific cause and rerun the failed check. Do not reinstall everything
or replace existing project files as a first response.
